# With Raspberry Pi Examples

Runnable examples for [With Raspberry Pi](https://ohyaan.github.io/).

## Categories

- [C++ Hardware Programming](cpp-hardware-programming/README.md)

Each category owns its build configuration. There is intentionally no repository-wide CMake project: future Rust, assembly and other categories can use the appropriate tools.

Development takes place on `main`. Build outputs and local preset overrides are not committed.
